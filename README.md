# BullBot Rogic Pro

IDE visual inspirada en Rogic para programación de robots.

## Características

- Sistema de bloques tipo Rogic
- DC Motor
- Servo Motor
- Dot Matrix
- Voice
- IF / ELSE
- LOOP
- WHILE
- BREAK
- Sensores IR y PIR
- Simulación de robot
- Arquitectura modular

## Estructura

```txt
index.html
style.css
app.js
blocks.js
renderer.js
executor.js
simulator.js
modals.js
```
